⚙️ Configurer l'API Football

GeoFoot Live utilise football-data.org — la meilleure API gratuite pour le foot. Inscription gratuite, pas de carte bancaire, données réelles en temps réel.

🏆 football-data.org RECOMMANDÉ GRATUIT ⚽ API-Football GRATUIT

Comment obtenir ta clé gratuite ?
1. Va sur football-data.org/client/register
2. Crée un compte (email + mot de passe, c'est tout)
3. Tu reçois ta clé API par email
4. Colle-la ci-dessus et clique Sauvegarder
Compétitions gratuites : Premier League, La Liga, Bundesliga, Serie A, Ligue 1, Champions League + 6 autres.
